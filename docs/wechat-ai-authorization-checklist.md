# 微信云端 AI 授权阶段检查（未验收）

## 已实现
- `claudia-wechat-ai-config`：基于 Supabase JWT 校验用户，按 user_id 验证绑定归属
- 显式 `authorize` 才保存 API Key（AES-GCM 加密，密钥只在个人 Supabase 的函数环境）
- `status` 不返回 API Key 或提示词
- `disable` 禁止领取新的云端 AI 任务；`delete` 删除密文配置
- UI 位于「设置 → 微信接入 → 微信账号绑定」，不增加顶层设置项

## 仍然存在的发布阻断
1. 需要对真实 Supabase 项目进行 SQL 迁移和函数部署，并确认匿名身份配置与 CORS。
2. 云端配置只支持显式填写的提示词和限定的 OpenAI-compatible 端点；本地 API Key 不自动上传。需要进一步完成角色、世界书、记忆和消息路径的有界、可撤销同步。
3. 停用只阻止**新领取**的 AI 任务；正在执行的任务仍可能完成。正式版应增加发送前授权二次检查和撤销语义。
4. 需要验证模型 API endpoint 的安全限制、加密密钥轮换、API 账单风险和用户授权撤销后的任务清理。
5. `qrcode.react` 依赖的 lockfile 尚未同步，构建未执行；不可宣称二维码 UI 已能运行。
6. 微信监听器仍只支持单实例，发送函数未部署，端到端真实微信收发未测试。
7. 对外公开网站的用户自己配置 Supabase，并不意味着服务端常驻进程自动启动；每位用户仍需要自己的运行环境，或另行设计多租户隔离服务。
8. iLink 接口能力、可用性及账号风险应在真实测试前核实。

不得合并 main 或部署 Production，直到以上问题解决。
