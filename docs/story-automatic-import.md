# 自动剧本准备（fix/story-import-simple-flow）

> 本页记录智能整理辅助服务；它已不再是创建/游玩的前置条件。当前玩家流程和失败恢复见 [原文直接游玩修复](story-direct-play.md)。

基于 af40bc9268e98e53b919cbc8e27fe576ac368866。该提交仅折叠审核界面，原创建/运行仍要求人工决定。本批接通后台自动准备，不修改 main、不部署。

## 玩家流程

上传 DOCX/TXT/MD（保留兼容 JSON）→完整归档→当前全局 API 逐段自动分析→完成后按原五步设置角色和开场→原 StorySession/StoryNode 开场、ABCD/自定义行动、重生和撤回。

界面不再含人工审核、片段跳转、规则搜索或 JSON 配置。没有上传文档时，仍走原有手工填写和推荐流程。上传是分析的主动触发；页面明确提示多次 API 费用，刷新、返回、取消或失败不自动重试。

## 证据与运行

- 每次2000字符以内、顺序遍历全文，不以采样代表全文；保留原始文件、完整文本、章节索引和引用范围。
- 逐条核验引用；计划/猜测保留为 planned/uncertain；缺少完整条件的部分段落不能自动成为确定规则。遗漏的段落保留原文和不确定标记，依预算在当前行动相关引用中取用。
- 自动检查结果与来源一起归档；“accepted”是旧结构的兼容字段，由程序填写，不需要玩家确认，也不代表语义真理。
- 普通背景不产生数值状态。明确机制可转为声明：带原文标签的变量、类型、初值、范围、只读标记、eq/gte/lte 条件事件与 set/increment 状态变化。不同 key 的关联不会凭空猜测。
- 自动编译采用保守的原文语法核验：初始值、范围、条件与效果的数值须匹配相应变量附近的原文。无证据、冲突或类型错误的提议不执行，保留相关原文作未决内容。
- 引用与冲突检查不是通用自然语言证明。复杂公式、跨段隐含条件、中文数词或歧义表达可能只作为原文参考而未编译；不宣称任意复杂模拟器均已完整转换。
- 原 Story 48KB 上下文预算下选取完整资料，规则/身份不前缀截断。必要内容超预算会在请求前停止。没有新增每回合摘要或规则分析请求。
- 仍按活动分支重放状态；重生不带旧版本，撤回不留下未来状态，原租约/revision/过期响应保护不变。

## 秘密

未公开秘密默认不给玩家可见生成模型；已知角色须有原文明示依据。明显秘密段落即使被AI漏标也保守屏蔽，跨片段秘密范围同样保护；不能把人物出现在秘密段落当作其知情证据。

输入/正文/选项/状态继续原证据校验。模型可能漏识别隐含秘密、猜测或语义改写，不能保证百分之百防泄露。仅自动编译明确的状态相等且向玩家公开的揭示条件；歧义、多条件或许可式规则继续保守延后，不提前透露。

## 恢复、成本与容量

- 分析片段在成功保存后缓存；手动重试复用已完成片段。Web Locks 排除同文档并发准备。
- 主库仍 Dexie v7，无迁移。旧人工审核归档仍可读，旧草稿可重新自动准备；新归档带可选 automation 元数据和来源核验。
- 已创建世界的原文、分析和状态配置随原ZIP覆盖/合并恢复；不依赖来源浏览器的临时文档库。未创建草稿仍仅在浏览器本地，不在ZIP中。
- 现有上传20MB、正文200万字符限制保留；单次自动任务最多120个分析请求，超过时明确停止，原文保留、不会发起分析费用。模型输出Token不超过用户配置及本功能6000的分析上限；低上限/截断会提示失败，不能假装准备完成。
- 世界归档仍限12MiB以兼容备份单记录上限；上传/准备超限不截断、不创建半个世界、不清空原文。该限制意味着并非所有可上传文件均能直接转为可运行世界。

## 验证边界

测试全部使用隔离数据库、合成文件和Mock模型。真实模型理解质量、任意复杂长文、人名知识推理以及真实 iPhone Safari/PWA/中文输入法尚需验收。截图来自实际应用的Mock准备页面，不代表真实模型或真机结果。
