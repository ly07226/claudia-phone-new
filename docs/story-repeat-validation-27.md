## 原有链路复核

`storyStore.readStoryPath` 仍沿 head 的父节点链校验世界、会话、序号并按先后排序。`claimStory` 在有效路径上调用 `storyInput`，重生先移除待替换末节点并保留该节点的玩家行动；`storyHistory` 根据当前行动和最近场景选择来源明确的历史摘录。`storyGeneration` 加入文档规则与现有模拟器状态，执行最终64KB UTF-8字节准入，再通过现有 Provider 请求。`storyResponse` 验证正文、四选项及状态结构；有效结果依旧通过事务提交。失败/部分输出不构成已提交历史；不从其他世界或自由聊天读取记忆。

PR #26 原本新增最近三轮候选选项、正文末尾450字符及重复剧情指导。其新增测试未发现编译错误：接手原样执行 typecheck 通过，原 continuity 文件 **11通过**。该测试主要验证输入字段和提示词，不能证明模型不会重复。

## 已证实的问题及最小修复

### 1. 字符截尾会丢失限定语

- 基线位置：PR #26 `src/storyContext.ts:19–22`，`n.body.slice(-450)`。
- 复现：完整正文以“以下是证人尚未核实的假设，不是已经发生的结果”开头，末尾包含“皇帝已经退位”。旧 `recentStoryBeats.ending` 只剩末尾450字符，失去开头限定，虽完整正文也在 `confirmedHistory`，附加摘录却给出缺少限定的重复材料。
- 确认：新的专项在修改前失败，收到的 ending 从句中间“验，档案仍待核验……”开始；不是主观推测。
- 修复：不再复制正文尾巴；`recentStoryBeats` 只传源节点、序号和 `confirmedHistory` 索引，指向已经准入的完整正文。近期窗口缩小时同步重建引用，不指向未提供节点。
- 边界：证明输入被字符截尾，不证明用户某次剧情重复必由此引起。

### 2. 最近选项不受独立预算约束，会挤掉前情甚至拒绝请求

- 基线位置：PR #26 `storyContext.ts:18,36,49`，三轮完整选项加入render，但未计入历史额度、也不能被舍弃。
- 复现：每项361字符（低于真实400字符限制）、三轮各四项，在19000字节可用预算中，已有短正文/当前行动本可保留，却返回 `budget`。新专项在原实现失败。
- 修复：候选选项按完整组保留、优先较新组，序列化上限6000字节；与完整历史及原文记忆一起计入原16–32KB历史分配目标，压力下先舍弃候选选项，再使用已有历史缩减策略。额外提供省略组数，不切半条选项；全请求仍受原64KB准入限制。
- 存档中的选项、玩家行动、正文完全不变。候选选项不是事实，也不会成为自动执行行动。

### 3. 重复输出的可观测性不足

- 原 `storyResponse.ts:58` 起只检查单次四项的标签和非空/重复；`storyGeneration.ts` 不比较跨回合的正文或选项。旧结果格式合法就可提交。
- 新增纯函数 `storyRepetition.ts`，接入已有数值诊断：完整正文是否与有效路径某节点完全相同、是否与最近三轮相同、四项中有多少与最近选项完全/近似匹配。
- 近似只用于数值提示：NFKC、大小写、标点/空白归一及长度至少8字符时的二元组Dice≥0.9；不认定语义相同，不记录文本或相似片段。
- **这不是语义拦截器**。合法的继续等待、再次询问、回忆也可能命中；诊断不拒绝、修改、自动补写或重试结果。无新UI或付费请求。旧存储与失败重试机制保持。

### 4. 指导应允许回忆而非禁止再次提及事件

保留 PR #26 初始资料/已确认结果的分层，收窄其“再次涉及同一事件必须新因果”的措辞：明确标注的回忆/讨论允许；若把旧事重演为新发生或改变既有结果，则需要新的因果依据。未增加人物风格、篇幅、固定剧情或关键词禁令。

## 剩余限制与成本

1. 没有真实模型/Provider调用、真实用户存档或iPhone设备；未用付费API，Mock不证明真实剧情质量。
2. 原有有界词法检索仍非语义事实账本；过大单元、同义表达、未被查询提及的状态可能漏召回。固定字节准入也不等于精确模型Token窗口。
3. 静态初始计划的真实权重尚未证实。模型可在收到正确前情时重复或矛盾；相似度诊断不是事实裁判，更不保证数百回合一致。近似选项只比较最近三轮；更早选项和换一种说法的旧事件仍可能重复。
4. 指令参考额外输入最多6000字节，加少量来源索引，并计入原有历史额度；正文尾部不再重复发送。实际输入计费因场景变化，不承诺零增加；没有新增请求、输出Token调整或后台任务。
5. 不将原始设定、角色或已存节点改写成自动推断“真相”；不需要重新导入剧本、审核规则或迁移数据库。
