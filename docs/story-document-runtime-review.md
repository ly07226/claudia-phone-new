## 已接入原剧情链路

1. DOCX/TXT/MD/受验证 JSON → 完整文本和原始文件字节归档；字节不发送模型。
2. 混合段落候选保留原文位置和 unreviewed 状态；逐段 AI 审核仍由用户点击，每次只发一个片段，不自动循环或重试。
3. AI 引用逐字核验；asserted / uncertain / planned 分开。人工确认不把计划强制转成事件事实。
4. 创建时冻结原文、原文件 base64、审核、确认与声明式运行配置，计算规范化 SHA-256。保存为 World 的可选 `storyDocument`，仍为 Dexie v7，无新表或迁移。
5. 普通叙事不使用数值状态。显式启用状态规则后，原 StorySession / StoryNode 链路增加声明校验、边界校验、只读字段、条件事件和活动路径重放。
6. 原有开场、ABCD、自由行动、重生、撤回、失败保留、租约与过期响应保护继续使用；没有第二个阅读器或独立游戏存档。
7. 原文与审核归档随现有 ZIP 导出、覆盖和合并恢复；恢复后的剧情不依赖来源浏览器的原文数据库。摘要对键排序不敏感，但修改内容会被拒绝。

## 运行声明示例（仅语法示例，代码不依赖这些字段）

```json
{
  "initial": {"clock":0,"resource":4,"available":false},
  "fields": {
    "clock":{"type":"number","min":0,"max":100},
    "resource":{"type":"number","min":0,"max":10},
    "available":{"type":"boolean","readOnly":true}
  },
  "events":[{
    "id":"condition_met",
    "when":{"key":"clock","op":"gte","value":2},
    "changes":[{"key":"available","op":"set","value":true}]
  }]
}
```

事件每条活动路径最多触发一次。只读字段只能被事件修改，模型不能直接设置。重生和撤回只重放有效路径；条件与知识公开按该路径重新计算。系统不从自然语言擅自编译具有歧义的数值公式。

## 知识与秘密

- 默认未公开的秘密不进入玩家可见模型输入；系统保留作者审核记录。
- 可审核：玩家开局是否已知、已知角色、原文保密词组、公开条件。
- 原文及明确保密词组在输入、正文、选项、结构化片段和状态中检查；拒绝不合规回合，绝不删除输出文字冒充成功。
- 已公开事实的角色知识用原文位置编号区分。涉及秘密的台词要求可靠结构化片段和相符说话人；不能确认时拒绝该回合。
- 玩家已经通过活动路径获知的信息，不随状态再次关闭而遗忘；回溯到获知之前则不再公开。
- **不保证语义改写的绝对防泄露。** 引用和词组检查不是语义证明。模型对未提供秘密的猜测仍可能偶然命中，角色知识的自然语言推理仍需真实模型与作者验收。
- 如果角色卡/公开设定包含未公开秘密证据，请求会被阻止；不会自动改写或截断角色卡。

## 预算与成本

- 不修改 Provider 配置、用户输出 Token 上限、正文篇幅选项、Daily 或 World 提示词。
- 不增加每回合额外模型调用。文档审核按用户点击计费，不静默扫描整本书。
- 为必要规则和状态预留原有 48000 字节输入预算；背景/事件/方向只选择完整引用，标记省略。关键规则仍放不下时在付费请求前拒绝。
- 原文最多200万字符，上传文件最多20MB；不做OCR，不执行Word宏/外部链接。保留制表符、换行及可读取附注，格式图片仍由原始文件归档保留。
- 为兼容既有16MiB单记录备份安全上限，单世界归档当前限制12MiB。超限明确失败、不创建世界、不截断，原文与草稿保留在本机。
- 创建前原文和审核草稿仍存现有独立浏览器库；未确认创建的草稿不在ZIP中。旧备份不可能恢复当时未包含的外部原文；不会猜造缺失资料或破坏旧数据。

## 仍需验收

- 模型状态提议的因果真实性仍需语义审查，确定性校验只保证类型、边界、字段权限、事件和分支一致性。
