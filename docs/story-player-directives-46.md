2. 原 `storyContext.ts` 的 `narration.perspective` 永远取旧世界设置；即使指导明确覆盖，人称字段仍可能与指导冲突。原默认篇幅目标也未随显式字数指导改变。修复后只在本次请求中解析有效值，初始世界/人物快照不改写。
3. 原PR只有提示词优先协议，不能阻止格式正确但人称/明确字数不符合的正文进入保存事务。本轮把可验证约束置于提交之前；失败不推进，不提前消耗指导。

## 输入优先级与保护

玩家选项/自由行动、启用的指导高于AI默认文风和未执行剧情安排；原始人物、历史、原文不是能覆盖这些输入的新指令。指导明确的人称优先于旧设置，显式字数优先于默认篇幅目标。不能把玩家的尝试写成成功，也不能擅自给玩家增加行动、台词、心理或同意；NPC仍可独立行动并给出合逻辑阻碍。历史事实、身份与世界硬规则不被新指令悄悄改写，发生真实冲突应交代世界回应。

保留现有归档、JSON/segments原文一致性、四个不同选项、模拟器类型/边界、有效父链、重生与回溯、API选择及Provider参数。没有数据库版本/表/节点结构变化；不扫描旧节点强制重写其人称。

## 运行实现

### 1. 当前有效指令（`storyDirectives.ts`、`storyContext.ts`）

- `narration.perspective/source` 使用本次有效人称；`outputRequirements` 明确记录客观约束，原指导全文仍完整发送。
- 支持常用中文“保持/改用/采用第一、二、三人称”等明确写法。否定语、NPC说话指令、带引号例子不直接当成叙述人称。多个明确正向人称按文本后出现者生效；不推断任意自然语言。
- 支持明确区间、至少/不少于、不超过/最多、约N字等有限数值语法。约1000字按800–1200个**body非空白Unicode字符**（含标点，不含choices和重复segments）验收；没有为所有默认篇幅新增硬门槛。
- 同时出现的量化约束取交集。矛盾或最低字数超过既有正文容量，在模型请求前报错，不默默选一条。
- 明确字数指导同步覆盖本请求的 `narrativeLength` 目标与诊断的最低目标；UI篇幅保存值和各Provider输出Token上限不变。
- 明确“对白比例不超过N%”检查可识别对白：合法结构化dialogue，或正文中明确有说/问/答等归属的完整引语。含糊对白不会假装能完整统计。

### 2. 提交前检查

`checkStoryDirectives` 使用平衡引号扫描、转义/嵌套引号和已校验NPC对白片段排除引语，再检测叙述中的明确错误人称表面特征；不是看到任何“我”就报错。对白“我”、书面引用“我”、我方/自我等有专项测试；未闭合引号不能隐藏后续整个正文。

仅有明显表面证据时拒绝。无代词、复杂倒装、未标注的引述、角色身份误标等仍可能漏检或误检，不能证明全文叙事视角绝对正确。segments也来自模型，原文一致不保证角色/类型标注语义无误，因此不能以标注排除宣称绝无漏检。

### 3. 最多一次纠正（共最多2次模型请求）

- 仅在完整正文/四选项及状态结构有效、但人称/明确量化指导检查不符时，再请求一次。
- 继续使用第一次的Provider、密钥、输出上限、原玩家行动、不可变历史和同一生成租约；不创建第二个逻辑回合，不重复提交玩家行动。
- 纠正输入是原始准入资料加固定代码/数字违规反馈；不把被拒候选作为历史，也不复述敏感正文到自动日志。要求重新返回完整且一致的body/choices/segments/状态。
- 两次共用原120秒期限和AbortController，第二次发送前再次检查世界、头节点、指导版本、租约和预算。暂停/取消/冲突不会隐式重启。
- 保留64KB输入准入；纠正放不进预算就停止。不提高Token上限、不自动换模型；首输出已达上限、网络、认证、拦截、JSON或状态失败均不触发新的这类纠正。
- 第二次仍不符、格式/传输失败或取消时明确报错，不再发第三次请求。
- 模拟器两候选都从原状态验证，只有最终合格节点进入事务；被拒候选不推进事件。
- 缓存的保存失败结果再次经过验收。合格结果本地保存失败后可沿用现有恢复机制，手动重试不重复付费生成。

### 4. 指导、错误与费用

单次指导只在合格节点的成功提交事务中停用；失败、取消、预算不足、版本冲突和保存失败均保留。持续指导不因纠正停用。重生失败保留旧节点与未来草稿，成功才替换叶节点，仍可撤回。

新增固定错误码 `directive-perspective/length/dialogue/conflict/budget`，沿现有失败UI和备份校验处理，不保存私人指导或正文到错误详情。现有数值诊断增加请求/纠正次数；单个response的usage不代表两次调用合计费用，以服务商计费为准。

读者操作区、指导、创建向导和开场状态的原有费用文案说明“最多额外调用1次纠正并计费”；仅改文字，不重新设计布局。**本功能确实可能增加一次API费用和等待时间**，不是零成本本地修正。默认篇幅不足不会因此自动补字。

## 可验证与不可验证边界

| 要求 | 本轮保证范围 |
| --- | --- |
| 选项/自由行动优先 | 原文完整传入且本次提示明确要求回应；纠正时不替换、不当作成功、不追加玩家行动。 |
| 指导覆盖旧人称 | 解析支持的明确指导生成有效字段并验收，世界原设置保留。 |
| 错误第一人称 | 有明确表面证据的叙述拒绝；合法NPC对白/引语排除，不能宣称是完整语言理解。 |
| 约N字、区间、显式对白比例 | 在上述语法和计数定义内验收；超过预算/容量报错，不无限补字。 |
| “少对白、多动作、慢节奏” | 全文传递并要求模型执行，但没有客观阈值，不能伪造严格运行时通过结论。 |
| 是否明确回应行动、擅自反转、代写新心理/同意 | 无通用可靠的本地语义裁判；本轮未以关键词/字符串出现与否封锁合理剧情，也不把正确Mock回复当成真实模型永远遵从的证明。 |

因此，仍可能出现**人称/数量合格但语义违背玩家意图**的结果；本补丁不能声称它们都会被拦截。自主行动、合理阻碍和“尚未成功”的语义例子有实际传递/提交测试，语义质量仍需真实模型评估。
