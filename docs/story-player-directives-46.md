# PR #45 / Issue #46：玩家指令优先与单次生成

## 最新用户要求（2026-11-13）

依据 [PR 评论](https://github.com/ly07226/claudia-phone-new/pull/45#issuecomment-6853210975)，此版本取代此前自动纠正方案。旧实现见提交 cfc4491；不得把旧报告的两次调用、风格拒绝规则当成当前行为。

## 当前实现

- 保留玩家选项、自由行动、启用的剧情指导的叙事优先协议。指导可覆盖本请求的人称和篇幅目标，不改写世界定义、人物或历史。玩家的尝试不等于成功；NPC仍可有合理阻碍，不能替玩家新增行动、台词、心理或同意。
- 每次主动生成最多发送一次模型请求。人称、约数字数、对白比例等表面特征仅记录固定警告代码和数值；不自动纠正、不自动重试、不因风格偏差拒绝完整可玩的节点。检查器异常也不阻断保存。
- 冲突的数量指导保留原始全文；不将不可能的 min/max 当成强制机器约束，回退本次UI目标，保留 conflict 提示。没有增加Token上限、模型切换或付费调用。
- JSON解析、四个有效不同选项、正文/segments完整性、模拟器状态、有效租约、指导/世界快照和提交并发保护仍为技术校验。技术失败保留原进度、行动草稿和指导，不能保存不可玩数据。
- 单次指导只在节点成功提交事务内消耗；保存失败可沿用现有本地结果缓存，主动重试保存不重复请求。重新生成成功才替换末节点，失败保留原节点，回溯逻辑不变。
- 旧版 directive-* 失败记录保留兼容读取，不迁移或删除数据；阅读器以旧版记录说明展示，不作为新的风格阻断。

## 卡片书写状态

当前底层可聚合SSE，但没有向Story阅读器提供实时、已解析的body增量。因此只在现有生成状态期间显示 **AI 正在书写…**，绝不定时虚增字数，也不统计JSON/选项。

最新剧情卡片左上角显示状态；开场尚无节点时在现有开场区域显示。完成后使用已保存body的非空白Unicode字符数显示 **本段 N 字**，含标点，不含choices和重复segments。状态位于正文排版之外，不改字体/对话/操作按钮，使用主题次要文字色，没有新增定时器、动画或叠层。历史卡片不重复显示状态。失败/取消沿用现有状态终止，不伪造成功。

## 安全与限制

没有修改数据库、Daily/World、Provider配置、记忆、备份格式或其他应用。没有真实DeepSeek测试或付费请求。自动化使用隔离数据库与Mock Provider；浏览器390/430布局测试不等于真实iPhone Safari验收。

风格检测是有限自然语言语法和表面文本启发式，不证明语义完全遵循；动作承接、人物自主性、隐含视角、动作密度等不能可靠自动判断。该版本按用户要求优先快速可玩，不再以不可靠语义检查阻断剧情。真实模型质量仍需用户验收。
