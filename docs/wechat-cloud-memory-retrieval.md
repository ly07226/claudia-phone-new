# 微信离线长对话记忆检索：当前实现

## 本轮实现
- 云端 AI 在每次微信消息到达时，除了最近 24 条，还可在当前授权上下文快照之后的最多 500 条历史微信消息中检索相关原文。
- 中文双字片段和英文单词匹配；最多选择 8 段、约 9000 字符，保留消息 ID、时间和发言方。
- 检索片段作为**不可信历史文本**提供给模型，不提升为系统规则；不会把模型的猜测写成永久事实。
- 只取已发送成功的 AI 回复，不把发送失败的回复当成发生过的对话。
- 每次重新同步本地上下文时推进快照时间边界，避免旧微信历史重复注入。
- 添加 `tests/wechat-memory-retrieval.test.mjs`，可用 Node 20+ 运行 `node --test tests/wechat-memory-retrieval.test.mjs`。

## 不能夸大的部分
- 这是**来源可追溯的有限历史检索**，不是无限轮次的 AI 长期记忆总结，也不是语义向量检索。
- 目前最多搜索最近 500 条云端历史候选；关键词不匹配时可能漏掉重要事件。
- 云端上下文快照只覆盖小手机上次授权同步的有效上下文；关闭期间本地未上传的数据仍不可读取。
- 真正的自动长期摘要需要来源映射、可撤销更新、模型调用预算、幂等、冲突处理和回放测试；不能用无来源总结替代。

- 当前代码不能宣称已经上线，不能合并 main。
